# Средоземье — энциклопедия по «Властелину колец»

Фан-сайт, посвящённый Средиземью: интерактивная энциклопедия персонажей, рас, мест и артефактов из мира Толкина. Многостраничный сайт на чистом JavaScript и CSS, собранный через [Vite](https://vitejs.dev).

## Возможности

- 🏠 Главная страница с анимированной сценой: Око Саурона, Барад-дур и **настоящее 3D-кольцо Всевластья** на `<canvas>` (проекция тора, вращение в своей плоскости, гравировка надписью на обращённой к зрителю половине).
- 📚 Разделы энциклопедии: **Персонажи**, **Расы**, **Места**, **Артефакты**.
- 🖼 Сетка карточек с детерминированными цветовыми палитрами (имя → цвет) и SVG-орнаментами, сигилами и артом.
- 🎨 Тёмная / светлая тема (переключатель в шапке, выбор сохраняется в `localStorage`).
- 🔍 Поиск и фильтры по разделам.

## Технологии

- [Vite](https://vitejs.dev) — сборка и дев-сервер.
- Чистый JavaScript (ES-модули), без сторонних рантайм-библиотек.
- SVG — декоративная графика (мотивы, сигилы, арт-композиции).
- Canvas 2D — 3D-рендер кольца Всевластья.
- CSS-переменные и мультистраничная структура.

## Структура проекта

```
src/
├── index.html            # Главная страница
├── pages/                # Страницы разделов (ПМ-навигация)
│   ├── characters/
│   ├── races/
│   ├── places/
│   └── artifacts/
├── css/                  # Общие стили (база, раскладка, карточки)
├── js/
│   ├── core/             # Навигация, страницы, поиск, тема
│   ├── data/             # Данные: персонажи, расы, места, артефакты, палитры
│   ├── pages/            # Логика страниц
│   ├── render/           # Карточки, грид, фильтры
│   ├── scene/            # 3D-сцена кольца (ring3d.js)
│   └── svg/              # Мотивы, сигилы, арт
└── public/
    └── favicon.svg
```

## Запуск

```bash
npm install     # установить зависимости
npm run dev     # запустить дев-сервер Vite
npm run build   # собрать продакшн-бандл в dist/
npm run preview # локально просмотреть готовую сборку
```
